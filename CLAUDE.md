This project contains tests from programming language, exercises in courses and samples of how to works any algoritmn.

## Rules

- Always use ./skills/CPP.md when will go changes files in ./CPP
- Always use ./skills/PHP.md when will go changes files in ./PHP
- Always use ./skills/Java.md when will go changes files in ./Java
- Not use ./skills/Java.md and ./skills/PHP.md when will go changes files in ./CPP
- Not use ./skills/Java.md and ./skills/CPP.md when will go changes files in ./PHP
- Not use ./skills/PHP.md and ./skills/CPP.md when will go changes files in ./Java

## Documentation

- All ways to execute a test or a program should be documentation in a README.md into the specific language or subproject.
