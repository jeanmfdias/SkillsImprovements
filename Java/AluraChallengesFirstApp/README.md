# Alura — First App Challenges

Standalone Java exercises from the introductory Alura course. Each file has its own `public static void main` and is meant to be run independently.

## Exercises

- [AreaCalculation.java](src/AreaCalculation.java) — area calculation
- [BankAccount.java](src/BankAccount.java) — basic bank-account simulation
- [Discount.java](src/Discount.java) — discount calculation
- [EvenOdd.java](src/EvenOdd.java) — even/odd check
- [ExchangeDollarToReal.java](src/ExchangeDollarToReal.java) — currency conversion
- [Factorial.java](src/Factorial.java) — factorial
- [GuessGame.java](src/GuessGame.java) — number-guessing game
- [MultiplicationTable.java](src/MultiplicationTable.java) — multiplication table
- [PositiveOrNegative.java](src/PositiveOrNegative.java) — sign check
- [Presenting.java](src/Presenting.java) — introduction
- [ProductPrice.java](src/ProductPrice.java) — product pricing
- [Profile.java](src/Profile.java) — profile printout
- [SameNumber.java](src/SameNumber.java) — equality check
- [Study.java](src/Study.java) — print statement demo
- [Subtraction.java](src/Subtraction.java) — subtraction
- [Sum.java](src/Sum.java) — sum
- [VariableCasting.java](src/VariableCasting.java) — type casting

## Run

Compile a single exercise and run it:

```
javac -d out src/Profile.java
java -cp out Profile
```
