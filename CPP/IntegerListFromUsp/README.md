# Lista de Exercícios de Inteiros da USP

[Link](https://www.ime.usp.br/~macmulti/exercicios/inteiros/index.html)

All exercises were written in C++11.

## Build

```
make            # compile every exercise into ./out
make clean      # remove ./out
```

## Run

```
./out/Exercicio01.out
```

## Exercises

1. Dada uma seqüência de números inteiros não-nulos, seguida por 0, imprimir seus quadrados.
2. Dado um número inteiro positivo n, calcular a soma dos n primeiros números inteiros positivos.
3. Dado um número inteiro positivo n, imprimir os n primeiros naturais ímpares.
4. Dados um inteiro x e um inteiro não-negativo n, calcular x^n.
5. Loja de discos: dadas as vendas diárias de março, determinar o dia de maior venda e a quantidade vendida.
6. Dados o número n de alunos e suas notas (0 a 100), determinar a maior e a menor nota.
7. Dados n e uma seqüência de n inteiros, determinar a soma dos números pares.
8. Dado um inteiro não-negativo n, determinar n!.
9. Dados n, i, j positivos, imprimir em ordem crescente os n primeiros naturais múltiplos de i ou j.
10. Dado n, verificar se é triangular (produto de três naturais consecutivos).
11. Dado n positivo, verificar se é primo.
12. Dados dois inteiros positivos, calcular o MDC pelo algoritmo de Euclides.
13. Dado n positivo, verificar se é perfeito (igual à soma dos divisores próprios).
14. Dado n, calcular o n-ésimo número de Fibonacci.
15. Dados n, j, m positivos, imprimir os n primeiros naturais congruentes a j módulo m.
16. Dado um natural na base binária, convertê-lo para decimal.
17. Dado um natural na base decimal, convertê-lo para binário.
18. Dados três naturais, verificar se formam os lados de um triângulo retângulo.
19. Dados três números, imprimi-los em ordem crescente.
20. Imprimir todos os milhares cuja raiz quadrada é a soma das dezenas formadas pela divisão. Ex: √9801 = 99 = 98 + 01.
21. Dados n e uma seqüência, contar segmentos de números iguais consecutivos.
22. Dados n e uma seqüência, determinar o comprimento de um segmento crescente máximo.
23. Dado n > 10, verificar se é palíndromo.
24. Dados p e q, verificar se p é subnúmero de q.
25. Simular a execução do programa fornecido para os pares (2,3), (5,2), (7,1), (0,5), (3,2).
